🚀 Getting Started

Clone the repository:

git clone https://github.com/<your-username>/ai_for_dld_udemy.git
cd ai_for_dld_udemy
Running HDL Code

Open the required Verilog or VHDL source files using an HDL simulator such as:

ModelSim
Questa
Vivado
Other compatible HDL simulation tools
Running Colab Notebooks

Open the .ipynb files in Google Colab:

Open Google Colab
Select File → Open notebook
Upload or select the required notebook
Run the cells sequentially
